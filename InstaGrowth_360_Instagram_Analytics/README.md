# InstaGrowth 360 – Instagram Analytics Dashboard

## Project Overview
InstaGrowth 360 is a Tableau analytics project designed to evaluate Instagram content performance and audience engagement. It brings post-level performance and supporting dimensions together so that content creators and marketing teams can understand what is working, identify weak areas, and make evidence-based publishing decisions.

**Project type:** Data Analytics / Social Media Analytics  
**Tool:** Tableau  
**Status:** Tableau dashboard completed

## Business Problem
Social media teams often track likes, comments, shares, and other engagement measures separately. Without a consolidated view, it is difficult to compare content categories and formats, understand performance over time, and identify which content deserves more attention.

## Project Objectives
- Measure overall Instagram content performance and engagement.
- Compare performance across content categories and content types.
- Track engagement trends over time.
- Identify high- and low-performing content.
- Support data-driven content planning and optimization.

## Dataset Files
| File | Purpose |
|---|---|
| `Content_Performance_Fact.csv` | Main performance and engagement records |
| `Content_Categories_Dim.csv` | Category lookup |
| `Content_Types_Dim.csv` | Content-type lookup |
| `Date_Dim.csv` | Calendar attributes for time-based analysis |

## Tools and Concepts
- Tableau Desktop: data connection, data relationships/joins, calculated fields, worksheets, dashboard layout, filters, and interactive analysis.
- Data analytics: KPI analysis, aggregation, comparisons, trend analysis, and data storytelling.
- Suggested measures include total posts, likes, comments, shares, reach/impressions, and engagement rate where those fields are available in the supplied data.

## Dashboard Analysis
The dashboard can be used to explore:
1. **Performance overview** – high-level engagement and content KPIs.
2. **Category analysis** – compare performance across content categories.
3. **Content-type analysis** – compare formats such as the types represented in the dataset.
4. **Time trends** – analyze how content performance changes by date, month, or other calendar periods.
5. **Top-performing content** – identify records with stronger engagement.

## Tableau Workflow
1. Open the `.twb` workbook in Tableau Desktop.
2. Confirm that the CSV data sources are connected. If the workbook was moved, reconnect each source to the corresponding CSV in this project folder.
3. Review the data model and confirm the fact table is related to the relevant dimension tables.
4. Validate field data types, especially dates and numeric measures.
5. Review calculated fields and KPI definitions.
6. Open each worksheet and check filters, sorting, and aggregations.
7. Open the dashboard, test all interactive filters, and verify that totals respond correctly.
8. Save the workbook after any path or formatting changes.

## Key Deliverables
- Tableau workbook: `INSTAGROWTH 360.twb`
- CSV source datasets listed above
- Interactive Instagram analytics dashboard

## Insights and Recommendations
Use the dashboard to prioritize categories and formats that consistently generate stronger engagement. Review weaker-performing content for opportunities to adjust creative approach, timing, and audience relevance. Validate conclusions across multiple dates rather than relying on a single high-performing post.

## Project Outcome
The Tableau dashboard consolidates Instagram performance data into an interactive analytical view, making it easier to compare content performance and support content strategy decisions.
